# Supabase CLI & Configuration Directory

This directory contains Supabase local development configurations, database migrations, and Row-Level Security (RLS) policy definitions.

## Directory Structure
- `config.toml` (Optional): Local Supabase emulator configuration generated by `npx supabase init`.
- `migrations/` (Optional): SQL migrations for custom database functions or triggers outside Prisma.
- `policies/`: Declarative SQL policies for Supabase Storage buckets and table RLS.
- `seed.sql`: Database seed scripts for local Supabase emulator testing.

## Useful CLI Commands
```bash
# Initialize local Supabase CLI configuration
npx supabase init

# Start local Supabase Postgres emulator (requires Docker)
npx supabase start

# Generate TypeScript types from live Supabase schema
npx supabase gen types typescript --project-id <your-project-id> > src/types/supabase.ts
```
